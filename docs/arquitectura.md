# Arquitectura

```text
Fuente de datos → Ingesta → Persistencia → Analytics → QuickSight
```

## Componentes
- **Ingesta:** obtiene y valida los datos de origen.
- **Persistencia:** almacena datos crudos y procesados.
- **Analytics:** realiza EDA, modelado y controles de calidad.
- **Dashboard:** comunica resultados y métricas al usuario final.
